# Godavari Pushkaralu AI Security System — Alert Levels and Dashboard Guide

## Alert Level Conditions

The system classifies crowd density and risk at each ghat into four alert levels, based on real-time data and AI model predictions:

### 1. GREEN (Safe)
- **Condition:**
  - Crowd density is less than 3 persons per square meter.
  - All parameters are within safe limits.
- **System Action:**
  - Routine monitoring.
  - No special action required.
- **Dashboard Message Example:**
  - "Crowd density at {ghat} is {density} persons/m² — within safe limits. Continue standard monitoring protocol."

### 2. YELLOW (Elevated)
- **Condition:**
  - Crowd density is between 3 and 5 persons per square meter.
  - Inflow is positive, indicating a growing crowd.
- **System Action:**
  - Recommend restricting new entries by 30%.
  - Alert crowd management personnel.
  - Pre-position response teams.
- **Dashboard Message Example:**
  - "⚠ ELEVATED ALERT: {ghat} density rising to {density} p/m². Recommend restricting new entries by 30%. Alert crowd management personnel."

### 3. ORANGE (High Risk)
- **Condition:**
  - Crowd density is between 5 and 7 persons per square meter.
  - Risk of stampede or crowd surge is increasing.
- **System Action:**
  - Close ghat entry gates immediately.
  - Deploy crowd dispersal teams.
  - Redirect pilgrims to alternate ghats.
- **Dashboard Message Example:**
  - "🔴 HIGH RISK: {ghat} density {density} p/m² exceeds safe threshold. CLOSE ghat entry gates immediately. Deploy crowd dispersal team. Redirect to {alt_ghat}."

### 4. RED (Critical/Emergency)
- **Condition:**
  - Crowd density exceeds 7 persons per square meter.
  - Imminent risk of stampede or life-threatening situation.
- **System Action:**
  - Full lockdown of the ghat.
  - Deploy police, NDRF, and medical teams immediately.
  - Activate mass emergency broadcast.
- **Dashboard Message Example:**
  - "🚨 CRITICAL EMERGENCY — {ghat}: Density {density} p/m² — STAMPEDE RISK IMMINENT. FULL LOCKDOWN. Deploy Police + NDRF immediately. Activate mass emergency broadcast. Medical teams to Ghat {zone_id}."

## Dashboard Alert Write-up

Each alert on the dashboard is generated by the AI system based on real-time crowd metrics and predictive models. The alert messages are designed to be actionable and informative for ground staff and command center operators.

### Alert Types and Their Meaning

- **GREEN:**
  - Indicates normal, safe conditions. No action required.
- **YELLOW:**
  - Early warning. Crowd is building up. Prepare to intervene if the trend continues.
- **ORANGE:**
  - High risk. Immediate action required to prevent escalation.
- **RED:**
  - Critical emergency. Maximum response needed to prevent casualties.
- **SUSPICIOUS:**
  - AI has detected unusual or suspicious crowd behavior (e.g., sudden density spikes, abnormal inflow/outflow, or behavioral anomalies).
  - Example: "⚠ AI Detection: Suspicious pattern at {ghat} — {reason}. Dispatching security officer to investigate."

### How Alerts Are Displayed
- Alerts are color-coded and shown in the dashboard's main and side panels.
- Each alert includes:
  - Ghat name
  - Current density
  - Risk score
  - Recommended action
  - Timestamp
- Alerts update in real time as new data arrives.

## Summary
- The system uses crowd density and other metrics to classify each ghat into GREEN, YELLOW, ORANGE, or RED status.
- Each alert is generated by AI models and is designed to prompt the correct operational response.
- The dashboard provides a live, actionable overview for safe crowd management during the event.
