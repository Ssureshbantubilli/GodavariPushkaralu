# Godavari Pushkaralu 2027

A website for the **Godavari Pushkaralu 2027** festival — the sacred Hindu pilgrimage held every 12 years on the banks of the holy Godavari River.

## 🕉 About the Festival

Godavari Pushkaralu (Pushkaram) is a grand religious festival celebrated once every 12 years along the Godavari River. It is observed when Jupiter (Brihaspati) transits into Simha Rashi (Leo). Millions of devotees from across India take a holy dip in the Godavari to seek spiritual merit, liberation (moksha), and blessings for their ancestors.

## 🚀 Getting Started

This is a static HTML/CSS/JavaScript website. To run it locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Ssureshbantubilli/GodavariPushkaralu.git
   ```
2. Open `index.html` in any web browser — no build tools or server required.

- **Trimbakeshwar** — Source of the Godavari, Maharashtra
- **Nashik (Panchavati)** — Where Lord Rama spent his exile
